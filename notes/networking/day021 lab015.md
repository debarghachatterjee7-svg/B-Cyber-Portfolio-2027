# 🌐 Protocol

A **protocol** is a standardized set of rules that allows two or more devices to communicate correctly over a network.

Examples:

- TCP
- UDP
- HTTP
- HTTPS
- FTP
- SSH
- DNS

Without protocols, computers would not understand how to exchange information.

---

# 🔷 TCP (Transmission Control Protocol)

TCP is a **connection-oriented** transport protocol.

### Characteristics

- Reliable
- Connection-oriented
- Packet ordering maintained
- Error detection
- Retransmits lost packets

### Used In

- SSH
- HTTP
- HTTPS
- Email
- Banking
- File Downloads

### Three-Way Handshake

```
Client
  │
  ├── SYN ─────────►
  │
  ◄── SYN + ACK ───
  │
  ├── ACK ─────────►
  │
Connection Established
```

---

# 🟢 UDP (User Datagram Protocol)

UDP is a **connectionless** transport protocol.

### Characteristics

- Faster
- Lightweight
- No guaranteed delivery
- No packet ordering
- No retransmission

### Used In

- Online Gaming
- Video Streaming
- Voice Calls
- DNS Queries

---

# ⚖ TCP vs UDP

| TCP | UDP |
|------|------|
| Reliable | Fast |
| Connection-Oriented | Connectionless |
| Ordered Packets | No Ordering Guarantee |
| Retransmits Lost Packets | No Retransmission |

---

# 🔌 Ports

A **Port** identifies a specific service running on a computer.

### Socket

```
Socket = IP Address + Port Number
```

Example

```
127.0.0.1:22
```

---

# 📌 Important Ports

| Port | Service |
|------:|---------|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |

---

# 🏠 Localhost

Localhost represents the current machine.

```
localhost
↓

127.0.0.1
```

This is called the **Loopback Address**.

Packets sent to localhost never leave the computer.

---

# 🌍 IP Address

An **IP Address** uniquely identifies a device on a network.

Examples

```
127.0.0.1
```

```
172.xx.xx.xx
```

```
192.168.x.x
```

---

# 📡 Ping

Ping is a networking utility used to verify communication between two devices.

It uses the **ICMP (Internet Control Message Protocol)**.

Example

```bash
ping -c 4 google.com
```

---

## Information Provided by Ping

- Packets Sent
- Packets Received
- Packet Loss
- Latency
- TTL (Time To Live)

---

# ⚡ Latency

Latency is the time required for one packet to travel from the sender to the receiver.

Measured in:

```
Milliseconds (ms)
```

Lower latency indicates faster communication.

---

# 📦 Packet

A **Packet** is a small unit of data transmitted across a network.

Large files are divided into many packets before transmission.

---

# 📉 Packet Loss

Packet Loss occurs when transmitted packets fail to reach the destination.

Ideal packet loss:

```
0%
```

---

# ⏱ TTL (Time To Live)

TTL limits the number of network devices (hops) a packet may pass through.

Each router decreases the TTL by one.

If TTL reaches zero, the packet is discarded.

---

# 🔗 Socket

A Socket uniquely identifies one network communication endpoint.

```
Socket

=

IP Address

+

Port Number
```

Example

```
localhost:2220
```

# 🛠 Linux Networking Commands

## Display Hostname

```bash
hostname
```

Displays the computer name.

---

## Display IP Address

```bash
hostname -I
```

Displays assigned IP addresses.

---

## Ping Host

```bash
ping -c 4 google.com
```

Tests external connectivity.

---

## Ping Localhost

```bash
ping -c 2 localhost
```

Tests internal communication.

# 📊 Socket Statistics (ss)

`ss`

stands for

**Socket Statistics**

Used to inspect active network sockets.

---

## Command

```bash
ss -tuln
```

### Option Breakdown

| Option | Meaning |
|---------|---------|
| -t | TCP |
| -u | UDP |
| -l | Listening Services |
| -n | Numeric Output |

---

## Purpose

Displays:

- TCP sockets
- UDP sockets
- Listening ports
- Local addresses
- Active services

# ⭐ Important Points

- TCP is reliable.
- UDP is faster.
- SSH uses Port 22.
- HTTP uses Port 80.
- HTTPS uses Port 443.
- DNS commonly uses Port 53.
- Localhost always refers to the current machine.
- Loopback Address is 127.0.0.1.
- Socket = IP Address + Port.
- Ping uses ICMP.
- Latency is measured in milliseconds.
- `ss` displays socket statistics.
