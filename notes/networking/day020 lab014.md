# 📘 Notes 014 — Introduction to Computer Networking & Basic Connectivity

## What is a Computer Network?

A computer network is a collection of interconnected devices that exchange information and share resources.

Examples:
- Internet
- School Computer Lab
- Home Wi-Fi
- Office Network

---

## Types of Networks

### PAN
Personal devices connected over a very short distance.

Examples:
- Bluetooth
- Smartwatch
- Earbuds

---

### LAN

Small local network.

Examples:
- Home
- School
- Office

---

### MAN

Network covering a city.

---

### WAN

Large network connecting multiple LANs.

Example:
- Internet

---

## Client

A device that requests services.

Examples:
- Laptop
- Smartphone
- Browser

---

## Server

A system that provides services or data.

Examples:
- Google
- GitHub
- OverTheWire

---

## IPv4 Address

A unique address assigned to every device.

Example

```
192.168.1.5
```

---

## Public IP

Visible on the Internet.

Assigned by the ISP.

---

## Private IP

Used inside local networks.

Ranges:

```
10.x.x.x

172.16.x.x – 172.31.x.x

192.168.x.x
```

---

## Localhost

```
127.0.0.1
```

Represents the local computer.

Communication never leaves the operating system.

---

## Hostname

Human-readable name of the computer.

Command:

```bash
hostname
```

---

## Packet

A small unit of data transmitted over a network.

Large files are divided into multiple packets.

---

## Protocol

A predefined set of communication rules.

Examples:

- SSH
- HTTP
- HTTPS
- TCP
- UDP

---

## Latency

Time taken for a packet to travel to the destination and back.

Measured in milliseconds (ms).

Lower latency is better.

---

## Bandwidth

Maximum amount of data that can be transmitted per second.

Usually measured in Mbps or Gbps.

---

## Throughput

Actual amount of data successfully transferred.

Usually lower than bandwidth.

---

## Packet Loss

Packets that fail to reach the destination.

High packet loss causes:

- Lag
- Buffering
- Slow communication

---

# Commands Learned

```bash
hostname

hostname -I

whoami

pwd

ip addr

ip route

ping localhost

ping 127.0.0.1

ping google.com

ping -c 4 google.com
```

---

# Important Observations

- Localhost is much faster than remote servers.
- Every device needs a unique IP address.
- Networks communicate using protocols.
- Large files are transmitted as packets.
- Understanding command syntax is as important as knowing the command itself.
