# 👨‍🏫 Professor Questions (Answered)

## 1. Why is `tar` different from `gzip`?

`tar` combines multiple files into one archive, while `gzip` compresses a single file. They are often used together because `tar` alone does not reduce file size.

---

## 2. Why do we often use `tar.gz` instead of only `gzip`?

Because multiple files can first be archived into one file using `tar`, and then that archive can be compressed with `gzip`. This makes storage and transfer much easier.

---

## 3. When would you choose `bzip2` over `gzip`?

When maximum compression is more important than compression speed, such as long-term backups or transferring very large files.

---

## 4. What information inside `/proc` is most useful during malware analysis?

The process status, memory information, command line arguments, parent process ID, and open file descriptors are extremely valuable for understanding suspicious processes.

---

## 5. Why does Linux separate stdout and stderr?

It allows normal program output and error messages to be handled independently, making scripting and automation much cleaner.

---

## 6. Why are pipes one of the most powerful Linux features?

Because they allow small commands to work together. Instead of writing complex programs, multiple simple commands can be connected into powerful workflows.

---

## 7. Explain a scenario where `curl` is better than `wget`.

When interacting with REST APIs, sending POST requests, testing HTTP headers, or debugging web applications. `curl` provides much greater flexibility.

---

## 8. How could an attacker misuse `tar`?

Attackers may archive stolen files before exfiltrating them, reducing transfer complexity and sometimes avoiding detection.

---

## 9. Why should defenders understand compression formats?

Attackers often compress malware, logs, or stolen data before moving them. Defenders must know how to inspect and safely extract these archives.

---

Because it allows me to quickly locate exactly the information I need without manually reading large amounts of text. It has become one of the commands I use most frequently.
