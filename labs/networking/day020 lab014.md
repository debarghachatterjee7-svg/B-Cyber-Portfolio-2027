# 🧠 Theory

Every device connected to a computer network is uniquely identified by an IP address.

Linux provides several utilities that allow users to inspect network configuration and verify communication between systems.

One of the most widely used diagnostic tools is **Ping**, which uses the **Internet Control Message Protocol (ICMP)** to determine whether another device is reachable and to measure the time required for a packet to travel to the destination and back.

Communication with **localhost (127.0.0.1)** occurs entirely within the operating system, while communication with remote systems traverses routers, switches, and Internet infrastructure.

# ❌ Error Analysis

### Incorrect Command

```bash
ping -c google.com
```

### Result

Linux returned an invalid argument error.

### Cause

The **-c** option expects a numeric packet count before the destination address.

### Correct Command

```bash
ping -c 4 google.com
```
