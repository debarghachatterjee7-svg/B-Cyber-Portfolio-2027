# 🔬 Practical Activities

## Activity 1 — Creating Test Files

Created two independent text files containing similar data with controlled differences.

Purpose:

To understand how Linux comparison utilities identify modifications.

Outcome:

Successfully prepared a reproducible testing environment.

---

## Activity 2 — Comparing Files Using diff

Compared both files using:

```bash
diff fruits1.txt fruits2.txt
```

Observation:

- Displayed the modified line.
- Clearly identified the changed content.
- Demonstrated line-based comparison.

Learning:

`diff` is best suited for comparing human-readable text files.

---

## Activity 3 — Comparing Files Using cmp

Executed:

```bash
cmp fruits1.txt fruits2.txt
```

Observation:

Reported:

- First differing byte
- Line number

Learning:

Unlike `diff`, `cmp` performs byte-level comparison and immediately reports the first detected difference.

---

## Activity 4 — Using comm

Sorted both files before comparison.

Executed:

```bash
comm fruits1_sorted.txt fruits2_sorted.txt
```

Observation:

Displayed:

- Lines unique to file one.
- Lines unique to file two.
- Common lines.

Learning:

`comm` requires sorted input to correctly categorise shared and unique entries.

---

## Activity 5 — Experimental Verification

Purposefully executed:

```bash
uniq
```

without sorting first.

Expected Behaviour:

Duplicate removal.

Observed Behaviour:

Only consecutive duplicate entries were removed.

After sorting first:

```bash
sort file | uniq
```

Duplicate removal worked correctly.

Learning:

This practical experiment demonstrated that Linux commands depend on the organisation of data rather than simply the data itself.

---

## Activity 6 — Line Counting

Executed:

```bash
wc -l
```

Verified the number of lines within the sample files.

Learning:

Useful for quick validation during scripting and log analysis.

---

## Activity 7 — Character Translation

Converted lowercase text into uppercase using:

```bash
tr
```

Learning:

Demonstrated efficient stream manipulation without modifying the original file.
