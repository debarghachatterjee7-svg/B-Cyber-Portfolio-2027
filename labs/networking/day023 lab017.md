# 🎯 Objective

The objective of this lab was to understand how Linux communicates over a network by exploring network interfaces, IP addressing, routing, DNS resolution, and HTTP communication.

This lab focused on interpreting networking information rather than simply executing commands. It also introduced command-line tools used extensively in cybersecurity, system administration, penetration testing, and CTF environments.

# 📚 Commands Performed

## 1. Inspect Network Interfaces

```bash
ip link
```

### Purpose

Displays all available network interfaces along with:

- Interface Name
- MAC Address
- MTU
- Interface State
- Link Type

### Observation

Successfully identified:

- Loopback Interface (`lo`)
- Ethernet Interface (`eth0`)

Observed:

- Interface was UP
- MAC Address was assigned
- Loopback interface contained no physical MAC address.

---

## 2. View IP Address Information

```bash
ip addr
```

### Purpose

Displays detailed IP configuration for every network interface.

### Observation

Identified:

- IPv4 Address
- IPv6 Address
- Broadcast Address
- Loopback Address
- Interface Scope

Confirmed that Linux separates loopback and Ethernet addressing.

---

## 3. View Hostname

```bash
hostname
```

### Purpose

Displays the computer hostname.

### Observation

Hostname successfully identified.

---

## 4. View Local IP Address

```bash
hostname -I
```

### Purpose

Displays currently assigned IPv4 address.

### Observation

Successfully retrieved active private IP address.

---

## 5. Display Routing Table

```bash
ip route
```

### Purpose

Displays routing information used by Linux.

### Observation

Successfully identified:

- Default Gateway
- Local Network
- Active Interface

Understood that packets destined outside the local subnet are forwarded to the default gateway.

---

## 6. Inspect DNS Configuration

```bash
cat /etc/resolv.conf
```

### Purpose

Displays configured DNS resolver.

### Observation

Successfully identified the active DNS nameserver configured by WSL.

---

## 7. Inspect Hosts File

```bash
cat /etc/hosts
```

### Purpose

Displays static hostname mappings.

### Observation

Verified localhost mapping.

Observed IPv4 and IPv6 localhost entries.

---

## 8. DNS Resolution

```bash
getent hosts google.com
```

### Purpose

Resolve a hostname into an IP address.

### Observation

Linux successfully queried DNS and resolved Google using an IPv6 address.

Repeated execution returned consistent results.

---

## 9. HTTP Header Inspection

```bash
curl -I https://example.com
```

### Purpose

Retrieve only HTTP response headers.

### Observation

Successfully viewed:

- HTTP Status
- Content-Type
- Server
- Date
- Cache Information
- Content Length

---

## 10. Retrieve Webpage Source

```bash
curl https://example.com
```

### Purpose

Retrieve webpage contents without downloading.

### Observation

Successfully received HTML source code.

Confirmed the difference between headers and page content.

# 📖 Key Learning

This lab demonstrated the complete networking workflow followed by Linux.

```
Application

↓

Network Interface

↓

IP Address

↓

Routing Table

↓

Gateway

↓

DNS Resolution

↓

HTTP Request

↓

HTTP Response

↓

Downloaded Content
```

Understanding this workflow provides the foundation required for:

- Linux Administration
- Networking
- Web Security
- API Testing
- Wireshark
- Burp Suite
- Penetration Testing
- Capture The Flag (CTF) Challenges
