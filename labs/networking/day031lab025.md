# 📋 Observation Questions

## 1. What is the difference between `ps` and `top`?

`ps` gives a snapshot of currently running processes, whereas `top` continuously updates information in real time. For quick inspection I would use `ps`, but for monitoring system activity I would prefer `top`.

---

## 2. Why does PID 1 matter?

PID 1 is the first process started during boot. It becomes the parent of many other processes and is responsible for managing the system. Without it, Linux would not function correctly.

---

## 3. What information is stored inside `/proc/<PID>/status`?

It contains useful runtime information such as:

- Process Name
- PID
- PPID
- Process State
- Threads
- Memory Usage
- User IDs

It helps understand what a process is doing.

---

## 4. Why do penetration testers frequently use `2>/dev/null`?

Because enumeration often produces many permission errors.

Using `2>/dev/null` removes unnecessary output and makes useful information much easier to analyse.

---

## 5. What happens if a background process is not terminated?

It continues running and keeps consuming system resources. If many unnecessary processes remain active, system performance may decrease.

---

## 6. Difference between `Ctrl+C` and `Ctrl+Z`?

`Ctrl+C` completely terminates the running process.

`Ctrl+Z` only suspends it so it can later be resumed with `fg` or `bg`.

---

## 7. Why are `&&` and `||` useful?

They make shell commands more intelligent.

`&&` ensures the next command only runs after success.

`||` executes a backup action when something fails.

These are extremely useful while writing automation scripts.

---

## 8. How does Linux keep track of every process?

Linux maintains a process table and exposes much of its information through the `/proc` filesystem. Every running process receives a unique PID and is continuously monitored by the kernel.

---

It helped me actually *see* Linux working instead of simply printing information. Watching processes update in real time made the concepts much easier to understand.
