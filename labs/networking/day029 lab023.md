## Exercise 1 — User Identification

Commands Executed

```bash
whoami
id
```

### Observation

Verified:

- Current username
- User ID (UID)
- Group ID (GID)
- Group membership

### Learning

Linux permissions are enforced using numeric user and group identifiers rather than usernames.

```bash
touch file1.txt

```

### Observation

Reviewed:

- Hidden files
- Permission bits

### Learning

Linux permissions are divided into:

---

## Exercise 4 — OverTheWire Bandit Level 19

### Objective

Retrieve the password for Bandit Level 20.

### Procedure

Listed available files.

Identified the executable:

```text
bandit20-do
```

Verified executable information using:

```bash
file bandit20-do
```

Confirmed effective execution user:

```bash
./bandit20-do whoami
```

Output:

```text
bandit20
```

Executed:

```bash
./bandit20-do cat /etc/bandit_pass/bandit20
```

Successfully retrieved the Level 20 password.

# 🔍 Technical Analysis

The most important observation from today's lab was understanding the difference between:

- Logged-in user
- Effective execution user

Although logged in as **bandit19**, the SUID executable temporarily executed commands with **bandit20** privileges.

This demonstrated how Linux securely delegates permissions without changing the authenticated user.

# 🌍 Real-World Applications

## 1. Linux System Administration

Administrators use identity and environment information to troubleshoot permission issues, configure software, and verify user sessions.

---

## 2. Cybersecurity

Ethical hackers inspect:

- User identities
- Group memberships
- Environment variables
- PATH configuration

to understand privilege boundaries and identify potential attack vectors.

---

## 3. Privilege Escalation Auditing

SUID binaries are routinely audited because incorrectly configured privileged executables may become privilege escalation vulnerabilities.

---

## 4. Digital Forensics

Incident responders inspect user identity and execution context to determine:

- Which account executed a program
- Under which privileges it ran
- Whether privilege abuse occurred

---

## 5. DevOps & Automation

Environment variables are heavily used for:

- Deployment pipelines
- Secret management
- Container configuration
- Cloud infrastructure
