# 🧠 Theory Learned

## 1. Every Running Program is a Process

Linux treats every running application as a **process**.

Examples:

- Bash
- SSH
- Firefox
- Python
- Cron
- Apache

Everything becomes a process.

Each process receives its own **PID (Process ID)**.

---

## 2. Parent and Child Processes

Every process is usually created by another process.

Example

```
init
 └── bash
      └── python
```

Here

- init is parent
- bash is child of init
- python is child of bash

This creates a hierarchy called the **Process Tree**.

---

## 3. PID

PID means

**Process Identifier**

Every running process has a unique number.

Example

```
bash → PID 594
```

No two running processes share the same PID.

---

## 4. PPID

PPID means

**Parent Process Identifier**

It tells which process started the current process.

Example

```
bash
 └── ps
```

Here

```
ps PPID = bash PID
```

---

## 5. Process Tree

Linux internally stores processes in a tree structure.

Example

```
init
 ├── sshd
 ├── cron
 ├── bash
 │    └── ps
```

Understanding this tree helps identify

- malware
- reverse shells
- privilege escalation
- suspicious parent processes

---

## 6. Cron

Cron is Linux's automatic task scheduler.

It executes commands automatically at fixed intervals.

Example

- every minute
- every hour
- every day
- every week

Cron is heavily used by

- backups
- updates
- monitoring
- malware persistence

# 💻 Practical Commands Practiced

---

## Current Shell PID

```bash
echo $$
```

Observation

Shows the PID of the current Bash shell.

---

## Basic Process List

```bash
ps
```

Observation

Displays processes running in the current terminal.

---

## Detailed Process View

```bash
ps -aux
```

Observation

Displays

- owner
- CPU usage
- memory usage
- PID
- running command

---

## Parent Child View

```bash
ps -ef
```

Observation

Displays

- PID
- PPID
- owner
- command

Useful for tracking process ancestry.

---

## Process Tree

```bash
pstree
```

Observation

Displays all running processes in a tree hierarchy.

Much easier to understand parent-child relationships.

---

## Forest View

```bash
ps -ef --forest
```

Observation

Displays parent-child processes using ASCII tree branches.

---

## Finding Cron

```bash
ps -ef | grep cron
```

Observation

Located the Cron daemon running on the system.

Security analysts spend a large amount of time investigating process trees.
