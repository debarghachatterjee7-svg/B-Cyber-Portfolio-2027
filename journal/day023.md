# 🧠 Major Concepts Learned

## 1. Network Interfaces

I learned that every network communication happens through an interface.

Linux maintains separate interfaces for

- Loopback
- Ethernet
- Wi-Fi
- Virtual Networks

I also understood why one machine may contain multiple interfaces simultaneously.

---

## 2. Loopback Interface

Today I understood that

```
127.0.0.1
```

is not "internet."

It simply represents my own computer.

Packets sent to localhost never leave my machine.

---

## 3. MAC Address

Every physical network card owns a unique MAC Address.

Linux displays it using

```
ip link
```

I now understand the difference between

- MAC Address
- IP Address

---

## 4. IP Addressing

Using

```
ip addr
```

I identified

- Private IPv4 Address
- IPv6 Address
- Broadcast Address
- Loopback Address

I also understood what

```
scope global
```

means.

---

## 5. Routing

Today I learned that Linux does not randomly send packets.

Instead, Linux consults the Routing Table.

The most important route is

```
Default Gateway
```

Whenever Linux doesn't know the destination,

it forwards packets to the gateway.

---

## 6. DNS Resolution

I understood the complete DNS resolution process.

```
Domain

↓

DNS Server

↓

IP Address

↓

Connection
```

I also learned the purpose of

```
/etc/resolv.conf
```

and

```
/etc/hosts
```

---

## 7. HTTP Communication

For the first time,

I inspected an HTTP Response manually.

Using

```
curl -I
```

I learned that every response contains

- Status Code
- Headers
- Server Information
- Content Type
- Date
- Cache Information

before the webpage itself.

---

## 8. curl vs wget

I now clearly understand their purposes.

### curl

Communication Tool

- APIs
- HTTP Requests
- Headers
- Debugging

### wget

Download Tool

- Downloads files
- Saves automatically
- Supports resuming
