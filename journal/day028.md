# 🧠 Theory Learned

## 🔹 Restricted Shells

A restricted shell limits the commands and operations available to a user. It is commonly used in production servers to prevent users from escaping into unrestricted environments while still allowing controlled access.

---

## 🔹 SSH Remote Command Execution

Instead of opening a normal interactive shell:

```bash
ssh user@host
```

SSH can execute a command immediately after authentication:

```bash
ssh user@host "command"
```

This allows administrators and automation tools to execute tasks remotely without maintaining an interactive session.

# 🔍 My Analysis

Initially, I considered logging in normally using SSH.

However, after studying shell startup behaviour earlier today, I realised that `.bashrc` executes only when an interactive shell starts.

Instead of trying to bypass the logout manually, I changed my approach.

I decided to execute a command directly through SSH:

```bash
ssh bandit18@bandit.labs.overthewire.org -p 2220 "cat readme"
```

This avoids opening an interactive shell entirely.

The command itself was conceptually correct. My first attempt failed because of an incorrect password entry, but after reviewing the previous level's password and re-authenticating correctly, the approach proved valid.

# 🧠 Professor Questions Answered

### Why do administrators use restricted shells?

To limit user capabilities while still allowing controlled access, reducing the risk of privilege escalation or accidental system modification.

---

### Why can SSH remote command execution work even if an interactive shell is restricted?

Because the command is executed directly by SSH without requiring the normal interactive login process that loads `.bashrc`.

---

### Why are shell startup files important?

They configure the shell environment, aliases, PATH variables, and login behaviour. Misconfiguration can affect both usability and security.

---

### Why is PATH important?

PATH tells Linux where executable programs are located. Without it, commands such as `ls` or `cat` would require full absolute paths.
