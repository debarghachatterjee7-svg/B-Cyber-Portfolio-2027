# 🧠 Understanding the Challenge

The official Bandit statement explained that the provided SUID executable would:

1. Connect to a localhost port specified as an argument.
2. Read one line of text.
3. Compare that text with the previous level's password.
4. If correct, transmit the password for the next level.

From this statement, I realised that **I needed to become the server**, while `suconnect` would behave as the client.

This mental shift was the key to solving the level.

---

# 🛠 Practical Workflow

The practical workflow involved:

- Inspecting the available executable.
- Confirming its privilege behaviour.
- Creating a TCP listener using Netcat.
- Automatically sending the previous password.
- Allowing the SUID program to connect.
- Receiving the next password after successful verification.

The complete communication occurred entirely on the local machine using the loopback interface.

---

# ⚠ Problems Faced

Initially, I did not completely understand how the executable worked.

I first assumed I needed to provide commands directly to the executable instead of creating a listener.

While experimenting, I also mistakenly typed:

```bash
nc-l
```

instead of

```bash
nc -l
```

Linux immediately reported that the command did not exist.

Rather than becoming frustrated, I carefully read the error message and realised the mistake.

I corrected the syntax and continued.

---

# 💡 Biggest Realisation

After analysing the challenge again, I understood that the executable itself was acting as a **client**.

Therefore, I needed to:

- Start a listener first.
- Feed the password into Netcat.
- Keep Netcat waiting.
- Execute `suconnect` afterwards.

At that moment the entire challenge became clear.

Instead of trying random commands, I understood the communication model.

---

# 🚀 Solution Strategy

My final workflow became:

1. Start Netcat in listening mode.
2. Pipe the previous password into Netcat.
3. Run Netcat in the background.
4. Execute the SUID program with the listening port.
5. Allow the program to authenticate.
6. Receive the password for Bandit Level 21.

This solved the challenge successfully.

# 🔍 Cybersecurity Concepts Learned

Today's challenge reinforced several important cybersecurity concepts.

## Local Client–Server Communication

Not every network interaction occurs across the Internet.

Many privileged services communicate only through localhost.

---

## Inter-Process Communication

Programs can securely exchange information using TCP sockets without interacting directly through files.

---

## SUID Privilege Delegation

Rather than giving users higher privileges, Linux allows carefully designed executables to temporarily execute with another user's permissions.

This is safer than permanently elevating privileges.

---
