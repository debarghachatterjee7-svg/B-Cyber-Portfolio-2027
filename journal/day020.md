# ❌ Mistake Encountered

Command executed:

```bash
ping -c google.com
```

Result:

Linux returned an invalid argument error because the `-c` option requires a numeric packet count before the destination.

Correct command:

```bash
ping -c 4 google.com
```

Learning:

Understanding command syntax is more important than memorizing commands.

# 💡 Key Learning

Today's biggest realization was that computer networking is governed by structured communication rules called protocols. Every piece of information transmitted over a network is divided into packets and follows standardized rules to ensure successful delivery. Even a simple utility such as `ping` demonstrates multiple networking concepts including packets, latency, routing, and protocol-based communication.
