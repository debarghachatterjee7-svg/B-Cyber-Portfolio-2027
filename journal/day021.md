# 📚 Topics Covered

## Module 01 – TCP vs UDP

### Concepts Learned

- What a network protocol is.
- Difference between TCP and UDP.
- Reliability vs Speed.
- Connection-oriented vs Connectionless communication.
- Three-Way Handshake.
- Practical use cases of TCP and UDP.

### Key Understanding

TCP guarantees reliable communication by establishing a connection before data transfer and retransmitting lost packets.

UDP prioritizes speed over reliability and is commonly used where small packet loss is acceptable.

## Network Connectivity Testing

Commands Executed

```bash
ping -c 4 google.com
ping -c 2 localhost
```

Observed

- Packet transmission.
- Packet reception.
- Packet loss.
- Average latency.
- TTL values.

Comparison

Localhost communication showed extremely low latency because packets never left the local machine.

Google communication showed significantly higher latency because packets travelled across the Internet.
